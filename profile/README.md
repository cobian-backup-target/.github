# Cobian Backup - A Copy You Have Opened Once

At a glance:
- Source folders you choose, one first
- A target on another disk
- A restore of one file before you trust the job
- Logs you can read, and originals that stay

## Name The Target

Cobian Backup is a backup of directories, not a guess about your whole PC. Create the task, set the destination, and say that path out loud. A wrong folder mixes your files into a place you still use for other work, or it fills the disk that holds the only copy.

Start with a small folder. Run the task while you watch. When it finishes, restore one file to an empty directory and open it. If a sentence or a pixel does not match, stop and fix the source. Do not add the documents folder until that file looks right.

## Schedule Later

A schedule is for a job you have already restored from. Daily copies of the wrong folder are still the wrong folder. Keep the target on a different disk from the files it protects. If one disk dies and it held both, you have no backup.

Passwords and encryption are optional and absolute. Lose the password and Cobian cannot invent it. Store it with the other secrets you already keep offline. Do not put the password only inside the backup.

## Logs And Misses

The log lists errors. A missed file may be open or locked. Close the program that holds it and run again, or accept that this run skipped it. Do not ignore a repeated error on the file you care about. The progress line is not a substitute for opening the restored copy.

## Not Someone Else's PC

Install the task on a computer you administer, for folders you may copy. Do not point it at another person's profile because the disk is visible. A network target must be an account you were given. If the login fails, stop.

## One File Proves It

Pick a text file you know. Restore it. Read it. That is the test you write down: the date, the target, and that the sentence matched. The next time you change the task, repeat a small restore. A green history without an open file is not proof.

## Leave The Originals

The backup is a spare. Deleting the working files because the task completed removes the copy you actually edit. Wait until you have opened a restore on a different disk. Then you still keep the originals if you need them for daily work. The archive is not the workspace.

## Player Profile

Cobian Backup fits a project you can name and a spare disk. It does not fit a machine you do not administer, a target you have not read, a forgotten password you hope someone can reset, or deleting originals the same day.

## Help Desk

The restored file is wrong? The source path is wrong or the task did not finish. Do not add more folders.
The archive will not open? The password does not match. It cannot be reset from email.
The log skips a file? It was locked. Close the app that holds it and run again.
The disk filled up? The target is the same disk as the data, or the source is too wide. Move the target.
You wanted another person's files? Do not add that path.

## Reader Notes

One folder, one run, one opened file. That sequence is the setup. The schedule is a convenience you earn after the sequence works.

Write down where the target lives. A backup you cannot find is not a backup. The password, if any, lives outside the archive.

Leave the working files where you use them. The copy on the other disk is the spare you hope not to need, and you have already proved you can read it.
